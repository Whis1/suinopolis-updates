# Suinopolis

App Windows indipendente per amministrare il Regno di Suinopolis.

## Versione 0.1.28 · Marce e incontri isolati

Scarica **Suinopolis-Setup.exe** dalle [Release](https://github.com/Whis1/suinopolis-updates/releases/latest).

Le marce mostrano una figura più grande per ogni tipo di truppa effettivamente inviata: Lanciere, Arciere, Soldato d’élite e Cavaliere. Nessun tipo estraneo al contingente e nessuna quantità o guarnigione privata resa pubblica. Le guerre di ritorno mostrano i tipi sopravvissuti. Nemici isolati da almeno quattordici caselle libere tra loro, con sette caselle dai castelli conservate. I gruppi già presenti vengono distribuiti senza azzerare HP, ricompense o durata; i bersagli di truppe in viaggio mantengono la posizione fino allo scontro. Testi roleplay con Andrà via tra… conservati.
