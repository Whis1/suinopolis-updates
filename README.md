# Suinopolis

App Windows indipendente per amministrare il Regno di Suinopolis.

## Versione 0.1.21 · Le voci del Regno

Scarica **Suinopolis-Setup.exe** dalle [Release](https://github.com/Whis1/suinopolis-updates/releases/latest).

Cronache: gli arresti ordinati dal Re ora riportano «Il Re ha fatto imprigionare Nomeutente». Sospensione ed esilio riportano «Il Re ha sospeso Nomeutente dal Regno» e «Il Re ha esiliato Nomeutente dal Regno». Le motivazioni restano visibili; anche le vecchie voci riconoscibili adottano le nuove frasi. Rimossi Ovest, Centro ed Est dalla tenuta; conservati i comandi dei settori produttivi. Permessi, effetti dei provvedimenti e dati riservati invariati.

Il Site non è stato aggiornato in questa pubblicazione; consultare le ricevute di distribuzione del progetto.
